# 基于图像识别与状态机调度的 GUI 自动化 agent：屏幕状态感知 → 收益决策 → 操作执行

**GUI Workflow Agent** 是一个独立的 Android 应用。当前案例是《三角洲行动》特勤处的制造工作台，涵盖状态检查、成品领取、补料报价、按预算续造和定时调度。此源码版本基于 **0.1.19**。

## 工作流程

1. **屏幕状态感知**结合截图、模板匹配和本机 OCR，识别工作台布局、制造状态、倒计时和补料报价。其他横屏尺寸会尝试自动校准，建议先用「查询补料」验证本机布局。
2. **收益决策**按工作台状态、置顶配方和四台各自的补料上限决定领取、补料、开工或跳过。补料上限默认为 0。当前规则依据用户设定的预算执行，不预测市场利润。
3. **操作执行**通过 Android 无障碍服务点击并核验结果。用户可随时停止。开启定时续造后，程序按本轮最晚制造完成时间安排下一次运行。0.1.19 在成功完成一轮收获续造后尝试返回桌面并锁屏。

按钮使用本地规则。AI 聊天是可选入口，使用用户配置的模型密钥，可发起检查、报价、收获或续造四项任务，补料上限仍由应用设置控制。

## 构建与验证

安装 JDK 17 或更高版本和 Android SDK 35。用 Android Studio 打开 `android/`，或在项目根目录执行下列命令。设置 `ANDROID_HOME`，或者在本地的 `android/local.properties` 中配置 `sdk.dir`。

```sh
sh android/gradlew -p android assembleDebug testDebugUnitTest lintDebug
```

公开源码可直接构建和运行单元测试。真机运行《三角洲行动》制造流程，还需在本地补齐[识别素材](android/app/src/main/assets/delta/assets/README.md)，再重新构建。系统要求 Android 11 或更新版本，运行时需启用该应用的无障碍服务。定时唤醒还需要闹钟权限，并要求设备没有 PIN、图案或指纹等安全锁。后台启动与锁屏表现取决于机型和系统设置。
